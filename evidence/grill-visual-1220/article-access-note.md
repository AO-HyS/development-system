Readable method, paraphrased for the pilot:

- Explore broadly before deepening one direction.
- Inject external variety with a generated seed when model defaults converge.
- Use ambitious, specific references and let the user steer taste from visible
  reactions rather than generic adjectives.
- Give an independent critic a screenshot and reference bar in fresh context,
  excluding implementation rationale.
- Ground criticism in visible criteria and examples. A score can support the
  judgment, but loops need careful stopping criteria; begin with one or two
  iterations and inspect convergence.
- Use image or motion media only when they improve the experience and verify
  their real behavior.
- Deliver by removing low-value elements and keeping attention on the task.

Local safety adaptations shared by all conditions: no API keys, paid providers,
product writes or generated motion; a working HTML prototype is required for the
panel interaction. The pilot does not treat a numeric score as approval.
