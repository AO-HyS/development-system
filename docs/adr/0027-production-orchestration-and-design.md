# ADR 0027: Publish the measured orchestration and durable design workflow

Status: accepted; operator authorized production publication on September 9, 2026.

Release1.14.0 includes the locally accepted1.12.0/1.13.0 changes and catalog0.35.0.
Astra Medium is the default orchestrator, OpenCode Go the ordered implementation
route, Luna Max with priority requested the Codex alternative. Factory, Droid and
Devin remain excluded from active execution. Specialist effort remains role-specific.

Four isolated runs on the same real Markdown-export task ended at11m38s for
Medium+Go,15m21s Low+Go,18m38s Low+Luna(blocked gate),20m39s Medium+Luna.
All passed independent product acceptance. Shared-machine concurrency, unequal
critique waits and one unresolved cancellation-gate failure limit causal ranking.
Medium+Go is a provisional default, not a universal performance claim. The
experimental product changes are retained privately, not shipped in this release.

Workers repeatedly loaded parent lifecycle instructions. Manage the operator's
existing global Codex instructions as a versioned artifact, preserving their
content and adding an explicit bounded-worker entry exception. Snapshot the
previous file on installation and restore it on rollback. This closes the global
entry conflict; it does not exempt workers from ownership, checks or authorization.

Ship the complete upstream Impeccable4.3.1 skill archive content (tag skill-v4.3.1,
commit cd12f8660e2dde57b9615c8a6b8ea674101f9cfc). Existing command shortcuts and
compatibility mirrors continue to route to the updated skill. The upstream engine
VERSION0.1.5 is a separate version from skill4.3.1. No project-local visual briefs
or product code are rewritten by the global installation.

Durable design-direction, project decisions, independent Astra critique before
final evidence, proportionate checks and bounded tool composition remain active.
Published historical artifacts remain immutable. Verify new hashes, install in an
isolated HOME, drift repair/rollback and required repo checks before publication.
