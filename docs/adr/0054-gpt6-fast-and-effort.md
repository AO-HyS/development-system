# ADR 0054: Exact GPT-6 profiles and observed coordinator effort changes

Status: accepted for the authorized repair candidate; publication and installation require separate evidence.

New native recommendations request Sol 6 High at normal speed for new coordinators, Sol 6 Medium for general writing, and Luna 6 High at priority speed for research, code mapping, mechanical writing and fast implementation. Astra 6 XHigh remains the plan author and independent plan/final reviewer. The single benchmark requests Sol 6 Medium at priority speed for its coordinator. Existing selected parents and historical explicit runtime routes are retained; OpenCode is no longer a new default. Model, effort and tier in a file or argv are requests. The host's applied settings and the provider's actual tier must be reported separately, with missing metadata unknown.

The coordinator can change effort only through the governed proposal, a passing current Jev return judgment and the exact later host turn observation bound to the pending transition. The model, provider, session, root and transcript stay fixed. A changed setting without that receipt grants no next-phase work. Astra plan and review effort remains XHigh. Cache reuse is not guaranteed by a stable conversation prefix; report available cached-token metadata without imputing savings when it is absent.

Release 1.28.0 snapshots the final reviewed runtime, new native profiles, roster and execution guidance in new immutable paths. Prior artifacts and manifests remain untouched. Existing active runs carry their original policy hash and evidence; a new runtime must not silently mutate, revalidate or rewrite them. Installation first preserves the current registry, locks and history, uses an isolated HOME for upgrade/rollback checks, and audits live host trust and identity separately from file hashes. An old binding whose policy hash no longer matches needs an explicit compatible completion or recovery path; absence of one is a blocked migration, never an implicit pass. No installed profile or passing fixture proves host enforcement, Fast delivery, or product acceptance.
