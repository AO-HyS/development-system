# ADR 0026: Carry design direction outside the conversation

Status: accepted for local implementation by the operator, September 9, 2026.

A successful NutriPlan visual conversation depended on an article, sequential
user corrections and generated boards. A new implementer could load Impeccable
without finding the new project brief. Requiring the operator to retell that
history defeats the purpose of reusable skills.

Add `design-direction` with a self-contained, attributed design method and a
small project-brief reference. Route visual discovery and approved-direction
handoffs to it from drive-development-flow, design-quality and grill-with-docs.
Keep the user's selected aesthetic and superseded decisions in project documents,
not in a universal product template. Existing Impeccable playbooks, critique and
final evidence remain responsible for their stages; reuse them once.

Use Matt Pocock writing-for-agents mechanics and Codex skill-creator. Article
techniques 1–6 are readable; the subscriber-only seventh technique is not claimed
as incorporated. Ordinary execution uses the packaged method without browsing.

Version 1.13.0 and catalog 0.34.0 add the skill and routing pointers without
rewriting historical artifacts. Verify catalog content, isolated installation,
existing repository gates and a fresh-context reader finding the project brief.
No automatic discovery, quality improvement or token savings is inferred from
installation alone. Product redesign and external publication are separate work.
