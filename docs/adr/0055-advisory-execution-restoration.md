# ADR 0055: Restore parent-owned advisory execution

Status: User authorized implementation, publication and operator activation.
Supersedes mandatory governance as the default in ADR 0047 through 0054.

Global Jev tool and Stop gates prevented ordinary work and kept historical failed
runs on the critical path. The operator selected the useful advisory method from
ADR 0046, preserving current GPT-6 roles and independent reviews.

Version 1.29.0 declares executionMode advisory-parent-execution explicitly.
The selected parent controls native execution; Jev advises at meaningful routing
and correction decisions. Classification errors create sanitized bound failure
receipts, and the parent can record a justified continuation without fabricating
a successful judgment or granting authorization. There is no automatic executor.

New sessions request Sol 6 High normal, research and exact/mechanical writing use
Luna 6 High priority, general writing uses Sol 6 Medium, and Astra 6 XHigh writes
the plan and performs distinct independent plan/final reviews. Requested settings
remain separate from host observations. No new benchmark is part of this release.

Setup and install resolve explicit profile behavior. Advisory installation removes
only marker-owned Jev handlers, preserves unrelated guards and histories, records
the actual before/after hook configuration, and keeps the original rollback
boundary across reinstall. A failed upgrade compensates contract and hook changes.
A same-version reinstall retains intentional repairs even if later skill sync
fails, reports failure, and preserves the original rollback boundary; it does not
reintroduce removed Jev handlers. Rollback preflights contract backups and hook drift.
Historical runtime commands remain available for explicit recovery; no old run
is silently resumed, relabeled or revalidated. Destructive protection, ownership,
required checks and operation-specific user authority remain in force.

Catalog 0.48.0 updates every reachable orchestration entry point and includes the
operator's field-notebook HTML reader and margin questions from candidate
fb6b5dd968281cd1a5c5563b940047102982a2fa (ADR 0056). This combines two previously
unpublished 1.28 candidates without rewriting either published contract history.
HTML and a sanitized temporary tunnel remain the default delivery surface.

Verification uses isolated HOME migration/reinstall/drift/rollback cases, failure
receipts, report questions, required verify/scenario and independent review.
Publication and operator activation are explicitly authorized; current installed
behavior is checked separately from source and fixture acceptance.
