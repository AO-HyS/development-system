# ADR 0037: Exact execution independent of model

Status: accepted for 1.21.0, September 15, 2026.

The user selected the exact-instruction method observed in benchmark arm A.
That single comparison supports a local process choice, not a causal model
ranking or a guarantee of equal capability. Supersedes the equal mode choice
in ADR 0035; all ownership, evidence and authorization boundaries remain.

Exact packets are the default. Outcome delegation requires an explicit reason.
The coding-orchestration execution contract owns ordered actions, expected
observations, bounded corrections and transferable evidence. Entry skills point
to this protocol; global instructions and model routing make the default portable.
Smaller packets and checkpoints adapt to capability without weakening acceptance.
The starting model stays parent; no named model or provider cascade is required.

A handoff preserves root, candidate, dirty work, ownership, accepted decisions,
authorization, completed and pending checks, failures and evidence applicability.
The former writer must stop before another takes ownership. Missing capability
or unknown runtime identity stays explicit. No new coordinator is introduced.

Publish new immutable artifacts, catalog and manifest. Verify installation,
drift, invalid-source rejection, reinstall, rollback and unrelated-file
preservation in isolated HOME. Production activation is explicitly authorized.
Installed bytes do not establish model parity or fresh-session skill discovery.
