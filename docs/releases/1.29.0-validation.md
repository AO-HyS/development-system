# 1.29.0 advisory execution and notebook reports

Jev is an adviser for routing and correction decisions. The selected parent owns
execution, independent review, verification and delivery. New advisory tasks do
not require global Jev tool/Stop hooks, phase permits or historical run recovery.
Historical governed records and explicit recovery commands remain available.

The installer removes only marker-owned Jev handlers, preserves unrelated hooks
and recovery-state bytes, and records exact rollback inputs. Reinstallation keeps
the original rollback boundary. Rollback preflights backups and later hook drift.
A failed classification produces a bound failure receipt; a justified parent
decision can continue without converting that failure into a passing judgment.

The user report candidate fb6b5dd968281cd1a5c5563b940047102982a2fa is incorporated
into contract 1.29.0 and catalog 0.48.0. Its notebook appearance, paragraph-linked
questions, persistent browser drafts and revisioned batch submissions remain.
The source inventory and narrow integration corrections are recorded in
config/1.29.0/report-source.json. Encoded path separators are rejected, and
question storage stays inside its dedicated directory.
