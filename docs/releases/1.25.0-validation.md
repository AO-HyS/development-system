# 1.25.0 validation and operational scope

This release implements user-authorized whole-feature governance. It preserves
the disabled historical automatic controller and keeps the selected parent in
charge. Installation and operational evidence are recorded separately.

## Acceptance evidence

- Permanent isolated lifecycle tests cover every phase, separate plan author and
  reviewer, concurrent disjoint workers, integration, correction of an actual
  high finding, current checks and accepted closure. They execute real OS
  processes with explicitly simulated model metadata; they are not provider
  certification.
- Denial regressions cover reused permits, wrong Post/PID attribution, unknown
  identity, unsupported child sessions, reused attempts, overlapping ownership,
  stale inputs/closure and interrupted ownership replacement. A dependent writer
  observes earlier integrated and sibling changes without claiming those edits.
- Installer/scenario checks use isolated HOME and demonstrate install, drift,
  failed validation, reinstall, rollback and preservation of unrelated files and
  hooks. Failed upgrades retain the preceding contract.
- Live Jev 1.13.0 at its pinned endpoint rejected a diagnostic with missing rules.
  Four additional negative cases rejected an open gating finding, missing ticket
  evidence, an omitted plan criterion and instructions to omit verification.
  These are bounded calibration cases, not a universal accuracy guarantee.
- Codex CLI 0.155.1 with actual Sol High and live Jev denied an unprepared write,
  allowed one exactly permitted read, and denied replay. The fixture remained
  unchanged and closed as blocked, as specified by the diagnostic. Its isolated
  hook definitions were inspected and enabled for that invocation only; this
  does not establish trust in an operator's separate host session.
- OpenCode 1.18.31 export metadata established the actual implementation worker
  as `opencode-go/deepseek-v4.1-flash`, effort `high`, for all 87 assistant messages.
  Requested flags alone were not used as identity evidence.
- A live process-adapter diagnostic reached accepted local closure after actual
  Luna High research, Astra XHigh plan authoring, a different Astra XHigh plan
  review, Flash High writing, a third Astra XHigh final review and an actual Node
  value assertion. Jev classified all lifecycle boundaries. The diagnostic was
  resumed after fixing real integration failures; failed attempts remain in its
  history. Its coordinator activation was an explicitly synthetic API fixture;
  the separate Codex/Sol host probe establishes real root-hook behavior.

## Capability boundaries

| Surface | Supported claim |
| --- | --- |
| Trusted Codex root hooks | Exact current tool permits, observed root attribution and bounded continuation |
| Fresh Codex CLI processes | Read-only fast research and separate Astra plan/review sessions with transcript identity |
| Attached OpenCode writer | Pinned launch, observed export identity, process lifetime, isolated candidate delta and explicit integration |
| Local verifier | Approved executable/argv, bound scripts/inputs and observed exit; interpretation remains with the parent |
| Native writable children | No general certification; unknown attribution blocks their governed route |
| Hosted tools and opaque nested code | No internal-tool governance claim; unsupported required routes remain gaps |
| Browser/visual behavior | Requires its own capable host adapter and real flow evidence; this release does not invent it |
| Nonvisual work | Same requirements, plan, independent review and closure chain; no mandatory visual stage |

A hook cannot block an operation when the host never runs it. Codex trust,
network access to Jev and supported tool delivery must be established in the
actual execution environment. External workers are not an OS security sandbox.
The runtime governs their launch/return, not every internal provider tool.

The independent security-review attempt was interrupted by an automatic content
filter. Its earlier concrete findings were addressed and functional regressions
were run, but that independent review remains incomplete. It was not retried
through another reviewer or provider and is not counted as passed.
