# Orchestration Pilot

Evaluate already-collected development-run records with the deterministic `orchestrator-pilot` interface. Include direct and sequential runs as well as multi-agent runs; a correct zero-agent choice is evidence.

The first checkpoint occurs after five non-trivial candidate runs or five calendar days. Compare comparable historical work instead of rerunning the same product task. Retain only when verified outcomes do not regress and waits, open lanes, or corrections improve without another coordination signal regressing. Otherwise collect more evidence or adjust the policy.

Return at most one first action per repository for Check-in. Keep the operation read-only. It never edits agent configuration, repositories, Linear, schedules, releases, or production.
