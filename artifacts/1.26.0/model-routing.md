# Model routing 1.26.0

| Stage | Requested profile | Responsibility |
| --- | --- | --- |
| Definition | Astra XHigh | Spec, decisions and linked tickets |
| Coordination | Selected parent; Sol High for new sessions | Scope, dispatch, integration, corrections, acceptance |
| Code/docs research | Available fast profile; native Luna High default | Bounded read-only source evidence |
| Implementation plan | Astra XHigh | Files, decisions, dependencies and exact packets |
| Plan review | Different fresh Astra XHigh | Independent requirements/risk review |
| Bounded writing | DeepSeek V4.1 Flash High | Execute settled packets with exclusive ownership |
| Deep review | Independent Astra XHigh | Correctness, security and affected specialist risks |
| Every lifecycle boundary | Jev 1.13.0 | Typed coverage, route, order, tools and missing-evidence judgments |
| Authorization | Deterministic governance runtime | Current receipts, actor/tool identity, ownership, dependencies and closure |

Fast research is a capability. An explicitly selected permitted Flash/GLM/other
profile can replace the default after runtime evidence; no automatic provider
fallback. Native profile files are requests, not observed identity. Existing
selected parents remain unchanged. Planning/review retain the strongest model.

Parallelism follows eligible dependencies, disjoint ownership and actual host
and provider capacity; there is no arbitrary two-worker policy. Shared provider
state must be serialized until isolation is proven. Browser/vision requires an
actually capable host. Pure backend work uses behavioral evidence without UI.

The active recipe is coding-orchestration/references/jev-governance.md. The old
advisory CLI remains compatible; its receipts do not authorize governed actions.
The quarantined automatic controller remains disabled. Installed hooks require
host trust and a verified session binding before enforcement can be claimed.
