# Operator interface 1.5.0

Ordinary software requests remain direct and proportional. Natural language is
the primary interface; command and skill names are optional escape hatches.

## Definition

- A new product idea normally routes through Product Grill With Docs, a compact
  Future Customer Story, Technical Grill With Docs, and then the proportional
  Working Backwards contracts.
- A settled, reversible, single-surface request may use the simple
  implementation path when the operator asks to implement it directly.
- Existing specs, tickets, implementations, and review targets resume at their
  current lifecycle stage instead of restarting discovery.

Generated documents never authorize implementation, external tracker writes,
commit or push, pull requests, merge, release, or production. Each operation
retains its own explicit authorization.

## Execution

Multiple-ticket execution is opt-in through `parallel-work` or equally clear
natural language such as “ejecuta estos tickets en paralelo.” The planner uses
ticket dependencies and owned surfaces to expose the current executable
frontier, assigns one writer per surface, and produces one integrated candidate
unless the operator gives a concrete reason for separate pull requests.

Git owns repository continuity. A changed commit is expected as work advances;
integration accepts verified descendant history and blocks divergence,
unverified ancestry, or conflicts.

## Harnesses

Codex is the native execution harness. T3 Code uses the Codex adapter. Factory
is not supported by this contract and must not be routed, installed, or used as
parity evidence.

## Quality and delivery

Changed surfaces select focused checks from declared stack capabilities.
Integrated certification, preview, data operations, production promotion, and
production smoke remain distinct gates. Provider evidence and rollback handles
are required before claiming a deployment.

## Human return

Natural phrases such as “ya llegué” route to Check-in. It reconciles current
evidence and returns only a short list of actions that actually need the human,
classified for mobile, computer, local device or secret, and promotion
authorization.
