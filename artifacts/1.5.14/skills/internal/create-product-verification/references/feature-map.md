# Feature Map minimum

Each entry is current repository truth, not an aspirational inventory:

```yaml
feature: stable identifier
surface: route or native screen
launch: command and environment
identity: role or isolated fixture
behavior: discriminating observable outcome
probes:
  before: deterministic state capture
  after: deterministic state capture
cleanup: reversible cleanup steps
evidence: private artifact directory
status: mapped | proven | blocked
```

Map only features that can be driven and observed. Keep product defects as
separate findings; do not silently edit product code while creating the
verification capability. The host owns evidence under
`$HOME/.development-system/private/verification/<run-id>`; never put evidence
or credentials in the repository.
