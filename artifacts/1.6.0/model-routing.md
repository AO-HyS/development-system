# Astra and OpenCode Go routing

Read the installed `agent-roster.json`. Astra owns decisions, UI, Computer Use,
ordinary review and integration. OpenCode Go GLM 5.3 Flash is the first writer;
the roster declares alternate Go models and Devin/Factory/Luna fallbacks.
Factory/Devin Fable assists complex review. Sol is retired from active policy.

Use argument arrays for provider invocation. OpenCode runs use
`opencode run --pure --model opencode-go/<model> --variant <effort> --format json`.
Permission flags and write ownership come from the current authorization,
never from the pure model resolver. Check local runtime metadata before
claiming a resolved model; a catalog listing proves availability only.

Remember typed provider failures until their observed reset time or an explicit
successful retry. Separate account quota from model unavailability; retain the
worker's diff and findings before switching. A progress checkpoint may expose
a stuck call, but never turns an unfinished review into approval.

Muse Spark Contributor is an experimental, synthetic/public-input candidate.
Its training policy and regional availability differ from the ordinary worker
route. Do not automatically send private repository content or task history
to it. A successful small probe is not evidence of general coding quality.

Efforts are initial task settings, not a universal speed ranking. Increase
effort for actual uncertainty or risk. Do not substitute unsupported effort
names between providers or silently fall back to another model.
