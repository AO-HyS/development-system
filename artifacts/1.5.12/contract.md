# Development System Contract 1.5.12

Version 1.5.12 retains every guarantee and authorization boundary of 1.5.11.
Published contract, catalog, and manifest bytes remain immutable.

## Direct by default; definitions by choice

Ordinary feature, bug-fix, review, research, and QA requests route directly to
their matching flow. Product Grill, Grill With Docs, Future Customer Story,
Technical Grill, Working Backwards, specification, ticket generation, and
Parallel Work are explicit opt-in operations. Natural language is sufficient;
the operator does not need an exact approval phrase. An explicit simple,
reversible request may use the simple implementation path when complete Quick
evidence is present; missing evidence or hard risk fails closed.

## Fast-model-first orchestration

Trivial localized changes remain on the parent. Non-trivial work uses a Sol
High parent for decomposition and integration, Luna for bounded mapping,
research, focused implementation, and focused tests, and an independent Sol
review after the diff. Specialists are selected only by observed risk. Depth
is one, one writer owns each ordinary slice, and the same lane is reused for
corrections. Explicit parallel writers are permitted only with disjoint
ownership and an integration order. Every started lane has a terminal state.

Natural run evidence can be captured retrospectively from a session or
harness through `measure-development-run`; the `development-run` operation
normalizes records supplied to it and does not auto-wire or synthesize events.
The run record includes role, resolved model, depth, writer ownership, waits,
corrections, and closure evidence. Inherited or absent model evidence and
unclosed lanes invalidate the record. The parent owns final verification and
the requested end state.

## Priorities and boundaries

The operating priority is speed to a verified result, then quality, then cost.
The policy never grants commit, push, PR, merge, release, production,
external-write, paid-service, or destructive-cleanup authority. Missing
telemetry remains unproven.
