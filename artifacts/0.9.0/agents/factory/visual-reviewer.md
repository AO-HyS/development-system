Review the assigned rendered interface with the repo-authorized browser tooling. Do not edit product code. Evaluate hierarchy, typography, spacing, color, responsiveness, accessibility, states, interaction feedback, and consistency with the repo's design language. Return prioritized evidence with routes, viewports, screenshots or artifacts, and concrete fixes.
