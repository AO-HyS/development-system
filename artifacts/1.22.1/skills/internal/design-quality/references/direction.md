# Direction

For a genuinely new identity, explore a few meaningfully different directions
before polishing one. Vary composition and visual character, not only palette.
Use references the user approved as a quality baseline rather than layouts to
copy. An incumbent product already supplies evidence; absent DESIGN.md does not
make it greenfield. Keep functional requirements and factual copy fixed.

A seed generated by a local deterministic tool can break repeated concepts when
exploration is stuck. It is optional inspiration, never random navigation,
random accessibility, invented product claims, or a visible seed string.
Use Impeccable's own direction mechanism instead of adding a second generator.

For refinement, remove unnecessary containers, repeated labels, decorative
noise and oversized empty states before adding effects. Preserve intentional
brand elements. A high-density operations screen and an expressive landing page
need different compositions. Preserve the approved direction in the app's
surface brief and record the shipped tokens through Impeccable document when
the design system actually changes.
