# Parent-owned advisory orchestration 1.24.0

This release adopts the measured Sol + Jev advisory workflow. The parent owns
the task; no separate scheduler, planning service, per-file engine or automatic
controller is added. New sessions default to Sol High, bounded writers use
Flash High, and native researchers/reviewers use Astra XHigh. The already
selected parent remains fixed. No Luna or automatic model substitution.

The active profile is config/1.24.0/orchestration-policy.json. Its advisory
classifier core and policy are byte-exact recovered sources from
1.2.0-candidate.3. The published wrapper supplies portable CLI and private
credential loading while preserving classifier and decision receipt behavior.

Jev receives compact packets at useful semantic boundaries and proposes routes.
The parent respects dependencies, owns permission and records its chosen route.
It executes through existing native/attached-process tools, serializes shared
state, verifies changed paths, integrates and accepts required behavior.
The installed coding-orchestration/references/jev-advisory.md is the executable
recipe and owns the packet, command, review and completion steps.

One provider response does not grant execution authority. An unavailable Jev
response is recorded once and the parent continues its judgment. Essential
writer/browser capability gaps remain explicit without provider substitution.
Repeated unchanged findings do not justify an endless retry loop.

Historical 1.23 artifacts remain immutable for recovery. The normal 1.24 CLI
and installed legacy driver reject the old automatic workflow. Installed hooks
do not rewrite requested models or claim automatic dispatch enforcement.

Measure complete product work through final close, including provider/tool
waits, review, corrections and acceptance. Exclude setup and explicit human
idle, preserve unknown usage, and distinguish first candidate from accepted
behavior. Installation, model loading, runtime use and product acceptance are
separate evidence claims. Use required focused validation without another
benchmark matrix merely to publish this packaging change.
